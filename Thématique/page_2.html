Overwatch

Les différents modes de jeu

Overwatch propose plusieurs modes de jeu :

- partie rapide :

Actuellement, le mode Combat à mort n'est plus disponible depuis cet onglet.

Le mode Partie rapide permet aux joueurs occasionnels de jouer sans réel enjeu.

Ce mode permet de découvrir de nouvelles cartes ainsi que de nouveaux héros.

Ce mode est lui-même séparé en trois options distinctes :

- Partie Rapide (file d'attente par role)

Ce mode permet de choisir le rôle que l'on souhaite jouer.

On peut jouer à ce mode uniquement en 5 contre 5.

Les équipes seront toujours composées d'un tank, de deux DPS et de deux supports.

- Partie Rapide 6V6

Ce mode nous permet de jouer en 6 contre 6, mais sans rôle prédéfini.

Les équipes peuvent être composées uniquement de DPS ou de supports : il n'y a pas de limite,

sauf pour les tanks, limités à deux par équipe.

À l'origine, ce mode était le mode de base d'Overwatch.

Mais en 2020, avec l'arrivée d'Overwatch 2, ce mode a été supprimé,

puis réintroduit en 2024 en phase de test, avant de devenir un mode de base avec sa version classée.

- Personnages mystères

Ce mode nous fait apparaître avec un héros aléatoire.

Mais dès qu'on meurt, le héros change automatiquement.

Ce mode nous permet aussi de découvrir de nouveaux héros que l'on n'aurait jamais testés.

Il se joue aussi en 6 contre 6, comme le mode précédent.

Le fonctionnement d'une partie rapide :

Une partie commence par le choix de la carte via un vote.

Nous avons le choix entre trois cartes.

Chaque carte a un mode de jeu spécifique :

le mode convoi :

Dans ce mode, nous devons défendre ou attaquer un convoi.

L'équipe qui attaque doit escorter le convoi jusqu'à sa destination finale pour gagner.

le mode capture de point :

Le but de ce mode est de capturer le point et de le faire monter à 100 %.

L'une des deux équipes gagnera dès qu'elle aura capturé deux points.

le mode hybride :

Ce mode est une fusion des deux modes précédents.

L'équipe qui attaque doit capturer un point, puis escorter le convoi

jusqu'à sa destination finale pour gagner.

le mode point chaud :

Le but de ce mode est le même que celui du mode Capture de point, mais il est plus rapide

et il faut capturer trois points au total pour gagner.

- le mode avancé :

Le but de ce mode est de pousser le robot jusqu'à sa destination finale, comme dans le mode Convoi,

sauf que les deux équipes doivent escorter le robot.

L'équipe gagnante sera celle qui aura amené le robot dans le camp adverse

ou celle qui l'aura amené le plus loin.

Une fois la carte choisie, les équipes choisissent leurs héros, puis la partie commence.

Une fois la partie terminée, nous voyons un court extrait de l'action de la partie,

puis les deux équipes votent pour la star du match.

Le joueur qui aura obtenu le plus de votes sera la star du match.
