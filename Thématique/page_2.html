Les differents modes de jeu

overwatch propose plusieur modes de jeu :

- partie rapide :

actuellement le mode combat a mort n'est plus disponible depuis cette onglet

le mode partie rapide permet au joueur occasionel de jouer sans rélle enjeu

ce mode permet de decrouvrir de nouvelle maps et aussi de decouvrir de nouveau heros

ce mode est séparer lui même en trois option distint :

- Partie Rapide (file d'attente par role)

ce mode permet de choisir le role qu'on shouaite jouer

on peut jouer a ce mode uniquement en 5V5

les equipes seront toujours composées de 1 tank, 2 dps et 2 healers

- Partie Rapide 6V6

ce mode nous permet de jouer en 6V6 mais sans role prédéfinie

les equipes peut etre composées que de dps ou de healers il n'y a pas de limite

a part pour les tank ou il y a une limite de 2 tank par equipe

a l'origne ce mode était celui de base sur overwatch

mais en 2020 avec l'arriver de overwatch 2 ce mode a été supprimé

puis réintroduit en 2024 en test puis en mode de base avec ça version clasée

- Personnages mystères

ce mode nous fait apparaitre avec un hero aléatoire

mais des qu'on meurt le hero change automatiquement avec un autre

ce mode nous permet aussi de decrouvrir de nouveaux heros qu'on aurait jamais tester

il est aussi en 6V6 comme le mode précédent

le fonctionnement d'une partie rapide:

une partie commence par le choix de la map via un vote

nous avons le choix entre 3 maps

chaque map a un mode de jeu spécifique :

le mode convoi :

le but de ce mode est que nous devons soit défendre ou attaquer un convoi

l'équipe qui attaque doit escorter le convoi jusqu'à la destination final pour gagner

le mode capture de point :

le but de ce mode est de capturer le point et de le mettre a 100%

une des deux equipe gagnera dés qu'il auront capturer un total de 2 points

le mode hybride :

le but de ce mode est une fusion des deux modes précédents

l'équipe qui attaque doit capturer un point puis escorter le convoi

jusqu'a la destination final pour gagner

le mode point chaud :

le but de ce mode est comme le mode capture de point sauf qu'il va plus vite

et qu'il faut capturer un total de 3 points pour gagner

une fois la map choisie, les équipe choisie leurs héro puis la partie commence

une fois la partie terminée, nous voyons un court extrait de l'action de la partie

et pour terminer les deux équipes devront voter pour la star du match

le joueur qui aura le plus de vote sera la star du match
